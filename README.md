# Varke-kohdekartta

Valtion tukeman asuntorakentamisen keskuksen (Varke) rakentamisen hinnan kohdelistauksen kohteet kartalla.

- Data: Varke, *Rakentamisen hinta – kohdelistaus, normaaliasunnot 24 kk*. Hinnat ovat osapäätöksessä hyväksyttyjä (sis. alv).
- Osoitteet: hankkeen nimestä tai verkosta haettu; geokoodaus Nominatim / OpenStreetMap.
- Taustakartta: © OpenStreetMap-tekijät. Maanmittauslaitoksen kartat saa käyttöön lisäämällä API-avaimen `index.html`-tiedoston kohtaan `MML_API_KEY`.

Sivusto on yksi tiedosto (`index.html`), joka julkaistaan GitHub Pagesilla.
